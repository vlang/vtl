# Covariance and correlation matrices

Compute sample covariance and Pearson correlation for variables stored in rows, matching the
`rowvar: true` convention.

## Run

From `~/.vmodules`:

```sh
v run ./vtl/examples/covariance_correlation/main.v
```

## Notes

The example uses four observations per variable and prints the resulting 2 by 2 matrices. See
[linear algebra tutorial](../../docs/TUTORIAL_LINEAR_ALGEBRA.md).
