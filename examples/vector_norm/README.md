# Vector norms over tensors

Compute L1, L2, and zero-order norms for a vector, L2 norms along matrix rows,
and an L2 norm over a tuple of tensor axes.

## Run

From `~/.vmodules`:

```sh
v run ./vtl/examples/vector_norm/main.v
```

## Notes

The zero-order norm counts nonzero elements. See [linear algebra
tutorial](../../docs/TUTORIAL_LINEAR_ALGEBRA.md).
