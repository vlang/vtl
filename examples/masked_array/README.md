# Masked array reductions

Demonstrates broadcastable missing-data masks, filling, compression, and
global or axis-wise reductions over valid values.

Run from `~/.vmodules`:

```bash
VJOBS=2 v run ./vtl/examples/masked_array/main.v
```

See [the tutorial](../../docs/TUTORIAL_MASKED_DATA.md) for API details and
current limits.
