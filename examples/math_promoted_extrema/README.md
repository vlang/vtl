# Promoted Elementwise Extrema

Demonstrates broadcasting mixed-dtype tensors through NumPy-style maximum and
minimum operations, including NaN-skipping `fmax` and `fmin` variants.

Run from the V modules directory:

```sh
cd ~/.vmodules
v run ./vtl/examples/math_promoted_extrema/main.v
```

See the [math ufunc tutorial](../../docs/TUTORIAL_MATH_UFUNCS.md).
