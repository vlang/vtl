fn (RealFftPlan[T]) forward #

fn (mut plan RealFftPlan[T]) forward(input &vtl.Tensor[T]) !&vtl.Tensor[complex.Complex]

forward computes a compact real FFT using the plan. The input length must match the plan length; a new output tensor is allocated for each call. The plan reuses an internal mutable work buffer, so calls on one plan must not run concurrently.

fn (RealFftPlan[T]) destroy #

fn (mut plan RealFftPlan[T]) destroy()

destroy releases the native PocketFFT plan. Repeated calls are safe.
