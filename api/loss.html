loss #

vtl.nn.loss

Differentiable objectives consume a prediction autograd.Variable[T] and a target vtl.Tensor[T], returning a scalar-like variable for backpropagation. This module currently provides:

Constructor Objective and input convention
mse_loss Mean squared error: mean((x - y)^2).
bce_loss Binary cross entropy: -mean(y log(p) + (1-y) log(1-p)); applies sigmoid by default (from_logits: true).
sigmoid_cross_entropy_loss Binary cross entropy from logits, using a sigmoid internally.
cross_entropy_loss -sum(y * log_softmax(logits)); raw logits with one-hot/soft targets.
softmax_cross_entropy_loss Multiclass cross entropy with softmax over logits and one-hot targets.
nll_loss Negative log likelihood from log probabilities after log-softmax; accepts class indices or one-hot/soft targets and optional per-class weights.
kl_div_loss sum(P * log(P / Q)); input is log(Q) and target is probability distribution P.
huber_loss 0.5 d^2 when |d| <= delta, otherwise delta (|d| - 0.5 delta), averaged.
smooth_l1_loss PyTorch-style 0.5 d^2 / beta when |d| < beta, otherwise |d| - 0.5 beta; supports none, mean, and sum reductions.

huber_loss and smooth_l1_loss are separate objectives: Huber scales its linear region by delta, while Smooth L1 divides the quadratic region by beta and has unit slope outside it.

Constructor signatures and reduction behavior are defined in the corresponding source files. In particular, binary cross entropy's from_logits setting and the expected representation for multiclass losses must match the model output.

cross_entropy_loss_with_options supports optional class weights, ignore_index, label_smoothing in [0, 1], and none, mean, or sum reductions. Use cross_entropy_loss_indices for Tensor[int] targets; it accepts a scalar target with logits shaped [C] or targets shaped [N, ...] with logits shaped [N, C, ...]. The generic cross_entropy_loss also accepts same-type integer-valued class-index targets and one-hot/soft targets matching the logits. For mean, weighted class-index targets divide by the sum of their non-ignored class weights; probability targets divide by the number of samples.

nll_loss(weight) uses mean reduction by default. Use nll_loss_with_options to select sum or per-sample reduction, or ignore a class-index target, while keeping the weight tensor optional:

objective := loss.nll_loss_with_options[f32](class_weights,
    ignore_index: -100,
    reduction: 'sum',
)

Use nll_loss_indices when class indices are stored in Tensor[int]; the regular nll_loss accepts a target tensor with the same element type as input. Both accept unbatched log-probabilities with shape [C] and a scalar class-index target, or batched log-probabilities with shape [N, C, ...] and class-index targets with shape [N, ...].

NLL none reduction returns one loss per target position (a scalar for an unbatched input). mean reduction divides by the total target weight when class weights are provided, and otherwise averages over non-ignored class-index targets. Matrix targets are an extra VTL extension; their weighted mean divides by the number of target positions.

import vtl.nn.loss

objective := loss.mse_loss[f32]()
loss_value := objective.loss(prediction, target)!
loss_value.backprop()!

See the neural-network tutorial for a training loop and loss tests for concrete input conventions.

struct BCELoss #

struct BCELoss[T] {
	from_logits bool
}

BCELoss computes Binary Cross-Entropy loss per element and returns the mean.

Formula (when from_logits = false): L = -mean(y·log(p) + (1-y)·log(1-p))

When from_logits = true (default), the stable logits form is used directly without materializing sigmoid probabilities.

Shape: input and target are both [batch, ...]; target values are in [0, 1].

Example

import vtl.nn.loss
l := loss.bce_loss[f64]()          // from_logits: true
out := l.loss(logits, labels)!

struct HuberLoss #

struct HuberLoss[T] {
	delta T
}

HuberLoss combines quadratic and linear error, controlled by delta.

Formula: L = mean(0.5·(x-y)²) if |x-y| ≤ delta L = mean(delta·(|x-y| - 0.5·delta)) if |x-y| > delta

Behaves like MSE for small errors and like MAE for large errors, making it more robust to outliers than pure MSE.

Example

import vtl.nn.loss
l := loss.huber_loss[f64](delta: 1.0)
out := l.loss(prediction, target)!

struct KLDivLoss #

struct KLDivLoss[T] {
pub:
	reduction string = 'mean'
}

KLDivLoss computes the Kullback-Leibler divergence loss.

Formula: D_KL(P ‖ Q) = sum(P · log(P / Q))

Input: [batch, n_classes] — Q log-probabilities (e.g. log-softmax output) Target: [batch, n_classes] — P probabilities (non-negative, sum to 1 per sample)

Fields:- reduction — 'mean' | 'sum' | 'none' (default: 'mean')

Example

import vtl.nn.loss
l := loss.kl_div_loss[f64]()
out := l.loss(log_q, p_target)!

struct NLLLoss #

struct NLLLoss[T] {
pub:
	weight       &vtl.Tensor[T] = unsafe { nil }
	ignore_index int            = -1
	reduction    string         = 'mean'
}

NLLLoss computes the Negative Log Likelihood loss.

Intended to be used after a log-softmax layer for multi-class classification.

Input shape: [n_classes] or [batch, n_classes, ...] — log-probabilities (log-softmax output). Unbatched class-index targets are scalar; batched targets omit the class axis or match the input shape for one-hot/soft labels.

Fields:- weight — optional per-class weight tensor (nil = uniform weights)

  • ignore_index — class index to ignore in class-index targets (default: -1 = none)
  • reduction — 'none' | 'mean' | 'sum' (default: 'mean')

Example

import vtl.nn.loss
l := loss.nll_loss[f64](unsafe { nil })
log_probs := log_softmax_output  // shape [batch, n_classes]
out := l.loss(log_probs, one_hot_target)!

struct SmoothL1Loss #

struct SmoothL1Loss[T] {
	beta      T
	reduction string
}

SmoothL1Loss computes PyTorch-style Smooth L1 with configurable reduction.

For error d, the loss is 0.5*d*d/beta when |d| < beta, and |d| - 0.5*beta otherwise. A beta of zero selects absolute error. This is distinct from Huber loss, whose outer linear region is scaled by delta.

Example

import vtl.nn.loss
objective := loss.smooth_l1_loss[f32](beta: 0.5)
result := objective.loss(prediction, target)!

struct SmoothL1LossConfig #

@[params]
struct SmoothL1LossConfig {
	beta      f64    = 1.0
	reduction string = 'mean'
}

SmoothL1LossConfig configures the transition point between quadratic and linear loss regions. Beta must be finite and non-negative; zero selects absolute error. The default beta is 1.
