Tensors, autograd and neural networks, natively in V.

VTL is a pure-V tensor library for numerical computing and machine learning — N-dimensional arrays, reverse-mode autograd, and a full neural-network module, powered by VSL kernels on CPU, CUDA and Vulkan.

Start building Browse the API

First tensor in under a minute

Install V, add VTL, and run real tensor code. VTL uses VSL as its numerical backend for linear algebra and scientific kernels.

# install both modules
v install vtl

// main.v — create, reshape, differentiate
import vtl

fn main() {
    t := vtl.from_array([1.0, 2, 3, 4], [2, 2])!
    println(t.get([1, 1])) // 4.0
}

Where VTL stands against NumPy and PyTorch

An honest ledger, not a marketing claim. Every row links to the tracked parity documents, which list what is implemented, partial, and still missing.

DomainStatusNotes
Array creation & manipulationImplementedCreation, reshape/transpose views, stacking, padding, sorting; copy-vs-view audit ongoing.
Indexing & set operationsImplementedAdvanced/mixed indexing, unique, searchsorted, take/put families, boolean masks.
Math, reductions & statisticsImplementedElementwise math, axis reductions, quantiles and histogram family via VSL.
FFT & linear algebraImplementedFFT modules plus VSL-backed decompositions and solvers.
AutogradImplementedReverse-mode graphs with fused gate backward kernels; gradient-checked.
Neural networksPartialLayers, losses, optimizers and sequential models; some CUDA backward paths still land.
GPU backendsPartialCUDA and Vulkan paths for selected ops; OpenCL compute dispatch incomplete.
Serialization & dataImplementedNPY/NPZ, CSV, model checkpoints and DataLoader utilities.

Full detail: NumPy parity tracker · PyTorch parity tracker. Gaps are tracked as GitHub issues and close only with API, tests and examples in place.

Performance, measured
